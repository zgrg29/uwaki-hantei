# 这算出轨吗？／これって浮気？判定シート

中日双语版，基于 [ikura1/uwaki-hantei](https://github.com/ikura1/uwaki-hantei) 的公开仓库 fork。

访问：https://zgrg29.github.io/uwaki-hantei/

- 仅勾选「中文」：简体中文界面。
- 仅勾选「日本語」：日语界面。
- 同时勾选：中文与日语上下对照。
- 全部 40 道题、按钮、结果说明、答案回顾、分享文字及结果图片跟随语言选择。
- 至少保留一种语言；自动记住语言偏好，切换语言不丢失答题进度。
- 静态网页，无构建依赖。在本目录运行 `python -m http.server 8092` 后打开本地地址即可预览。

`index.html` 保留原题目与评分逻辑；`i18n.js` 提供翻译、语言切换和结果图片；`i18n.css` 提供双语排版。

原仓库目前未声明开源许可证。本 fork 不新增或推定对原代码、题目及设计的许可；原有权利归相应权利人所有。

## 原项目说明 / 元プロジェクト

# これって浮気？判定シート

全40問を「① 浮気 / ② 浮気じゃないけど嫌 / ③ 全然OK」の3択で答えると、判定タイプと結果画像が出て、X にポストできる診断ページです。

公開ページ: https://ikura1.github.io/uwaki-hantei/

出典: 健屋花那さん（[@sukosuko_sukoya のポスト](https://x.com/sukosuko_sukoya/status/2107121927278166034)）の「これって浮気？判定シート」をもとに作成しています。

シートデザイン: ありあさん（[@air_trpg](https://x.com/air_trpg)）

中文使用随站加载的资源圆体（500 / 700 / 900），匹配原版圆润粗体风格；日语保留原版字体。字体来源及许可见 [fonts/README.md](fonts/README.md)。
